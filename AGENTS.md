# MusicCraft -- AGENTS.md

**Purpose**: Pure-Rust ArtCraft DAW arrangement, virtual vocal synthesis, stem separation, and offline mix rendering studio (`musiccraft-core`, `musiccraft-mcp`, `musiccraft-app`).

## Architecture (3-Tier ArtCraft Containment Harness)
- **L1 (`crates/musiccraft-core`)**: SongProject AST (`.mcraft`), WAV PCM I/O, formant vocal synthesizer, 4-band stem splitter, offline mix renderer, DJCraft handoff packager, and universal `Command::dispatch` bus. `#![forbid(unsafe_code)]`, zero UI/CLI/MCP dependencies.
- **L2 (`crates/musiccraft-mcp`)**: Unified CLI (`clap` + `--json`) and MCP `2024-11-05` stdio server (`mcp` subcommand) sharing `Command::dispatch`. `stdout` is 100% pure JSON-RPC in `mcp` mode; all logs go to `stderr`.
- **L3 (`crates/musiccraft-app`)**: Pure-Rust `eframe` / `egui 0.37` Pattern 2 DAW workstation calling `musiccraft_core::dispatch` directly in-process. Implements the 8-menu Craft Menu Bar (`File`, `Edit`, `View`, `Insert`, `Modify`, `Commands`, `Window`, `Help`) with `switch_on_hover`, the 5-item Help suite, `harsh_visuals()`, Tofu Guard, and `--smoke`.

## Normative Boundary
- **MusicCraft is the studio; `djcraft` is the stage.** MusicCraft arranges, synthesizes vocals, splits stems, renders mixes, and exports a handoff package (`handoff.json` + stems) for `djcraft`. Live 4-deck mixing and Camelot performance stay in `djcraft`.

## Merge Gates

